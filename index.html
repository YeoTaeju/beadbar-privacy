1. О приложении

Политика описывает обработку данных в отдельной Android-версии игры «Мастерская: Сортировка бусин». Она не относится к браузерной версии на платформе Яндекс Игры и не заменяет условия RuStore или других сторонних сервисов.

Для игры не требуется регистрация. Покупок за реальные деньги нет. Основные уровни работают без интернета: игровые файлы находятся на устройстве. Для рекламы требуется подключение к сети.

В текущей версии нет общего серверного рейтинга, облачного аккаунта и синхронизации прогресса между устройствами. Доступность приложения по странам определяется условиями распространения и настройками магазина.

2. Игровое сохранение

Для продолжения игры на устройстве сохраняются:

  • текущий и лучший пройденный уровень, игровые монеты, выполненные заказы;
  • открытые и выбранные оформления, состояние ежедневных наград и обучения;
  • настройка звука и время изменения сохранения.

Сохранение находится в локальном хранилище игрового WebView и в закрытой папке приложения. Дополнительная копия в этой папке тоже локальная, а не облачная. Приложение не отправляет прогресс на сервер разработчика. Незавершённая раскладка уровня не сохраняется.

Локальные данные хранятся до их изменения или удаления. Чтобы удалить их, откройте сведения об игре в настройках Android и выберите очистку данных приложения. Прогресс, монеты и настройки будут потеряны. Удаление приложения также удаляет его обычные локальные данные; у разработчика нет серверной копии для восстановления.

Отдельно на устройстве сохраняются ваш выбор обработки данных рекламным сервисом, версия текста выбора и время его сохранения. Эти сведения нужны для применения выбранной настройки.

3. Реклама и выбор пользователя

В игре используется Yandex Mobile Ads SDK: реклама между уровнями и добровольная реклама за игровые награды. До первого ответа на запрос о конфиденциальности приложение не инициализирует рекламный SDK и не загружает объявления.

Ответ «Согласен» или «Не согласен» передаётся SDK и определяет выбранный режим обработки данных. При отказе используется режим без согласия. Играть можно при любом ответе.

Отказ от согласия — не отключение всей рекламы. Доступность объявлений определяет рекламный сервис. Реклама с наградой запускается по рекламной кнопке, а награда выдаётся только после подтверждения просмотра рекламным сервисом.

При загрузке и показе объявлений технические сведения передаются непосредственно сервисам Яндекса. Они могут включать IP-адрес, сведения об устройстве и программном обеспечении, рекламных запросах и показах. Предзагрузка объявления также обращается к рекламному сервису. Данные используются для работы, подбора и оценки эффективности рекламы.

В приложении отключены отслеживание местоположения рекламным SDK и необязательный отчёт App Ad Analytics. Разрешение Android на рекламный идентификатор AD_ID исключено из манифеста. Ограничение сбора данных рекламного SDK применяется ко всем игрокам без определения их возраста. Эти меры не означают полной анонимности или отсутствия технических данных при сетевом обращении.

Игра не запрашивает разрешения на доступ к контактам, SMS, камере, микрофону или геолокации. Отдельная аналитика разработчика не подключена; собственный сервер разработчика не получает игровой прогресс или выбор конфиденциальности.

По документации Яндекса описываемые им пользовательские данные SDK защищаются при передаче посредством HTTPS/TLS. Состав обработки зависит от настроек SDK. Условия обработки, хранения и обращения по данным рекламного сервиса описаны в политике конфиденциальности Яндекса и документации Yandex Mobile Ads.

4. Обращения в поддержку

Если вы пишете на zhabsterenko@gmail.com, разработчик получает адрес отправителя, текст письма и приложенные вами материалы. Они используются для ответа, разбора проблемы и рассмотрения обращений о данных. Отправка письма не требуется для прохождения уровней.

Переписка хранится, пока рассматривается обращение. После решения вопроса письма и вложения удаляются в течение 30 дней, если более длительное хранение не требуется по закону. Этот срок относится к экземплярам переписки, которыми управляет разработчик. Хранение технических и резервных копий почтовыми провайдерами определяется их правилами.

Почта поддержки обслуживается Gmail. Передача и хранение переписки связаны с работой почтовых провайдеров отправителя и получателя. Условия обработки данных Google приведены в политике конфиденциальности Google. Использование этих сервисов не означает хранения всех данных исключительно в России.

Пожалуйста, не отправляйте пароли, платёжные реквизиты или документы, не относящиеся к вашему вопросу.

5. Управление данными

Изменить выбор обработки данных можно в игре: системная кнопка Android «Назад» на главном экране → «О приложении» → «Конфиденциальность». Для отзыва согласия выберите «Не согласен».

При открытии настроек конфиденциальности приложение сбрасывает загруженные объявления и отменяет ожидающие загрузки. После сохранения нового ответа последующие рекламные запросы используют его. Отзыв не удаляет автоматически ранее переданные данные и не означает немедленного прекращения всех внутренних соединений SDK.

По вопросам обработки данных, их уточнения, удаления переписки или реализации других предусмотренных законом прав напишите на zhabsterenko@gmail.com. Укажите название игры и суть обращения. Запрос будет рассмотрен с учётом применимых требований.

Игровое сохранение удаляется на устройстве, как описано в разделе 2. Очистка данных игры не удаляет отправленные письма или данные, уже переданные Яндексу. Для данных, обрабатываемых сторонними сервисами, действуют также способы обращения и сроки, указанные в их политиках. Разработчик не может обещать удаление всех данных стороннего сервиса одним письмом в поддержку игры.

6. Возрастная аудитория

Игра предназначена для общей аудитории и не разрабатывалась специально для детей младше 13 лет. Заявленная разработчиком возрастная маркировка игры — 0+. В приложении нет возрастного барьера: возраст и дата рождения не запрашиваются.

Ограничение сбора данных рекламным SDK применяется ко всем игрокам. Это не утверждение о возрасте конкретного пользователя и не фильтр возрастного содержания объявлений. Подробнее об ограничении данных: документация Яндекса.

Родитель или законный представитель может обратиться по вопросам данных ребёнка на почту поддержки.

7. Эта веб-страница

Страница политики размещается на GitHub Pages. В её код не добавлены аналитические счётчики, рекламные скрипты, формы сбора данных или сторонние шрифты.

При посещении сайта GitHub Pages GitHub записывает и хранит IP-адрес посетителя для обеспечения безопасности, в том числе без входа в аккаунт. Это описано в документации GitHub Pages. Условия сервиса приведены в политике конфиденциальности GitHub.

При переходе по внешним ссылкам обработка данных соответствующим сайтом регулируется его собственной политикой.

8. Изменения политики

Актуальная редакция публикуется на этой странице с датой обновления. При добавлении новых способов обработки данных, например облачного сохранения или общего рейтинга, политика будет обновлена до выпуска соответствующей версии игры.

Когда это требуется, пользователю будет предложено отдельное уведомление или запрос согласия. Само чтение этой страницы не является согласием на обработку данных.
